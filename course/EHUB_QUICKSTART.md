# Group 9 — eHub 快速使用與雙機測試

> 給兩位主播和測試觀眾使用。先確認管理者已把 `codex/chat-i18n-gif` 版本部署到公開網站；GitHub 分支存在不代表公開網站已更新。

## 先開網站

開啟 Group 9 公開直播間：

<https://group9liveb11302133.japaneast.cloudapp.azure.com/group9/>

右上角按 **English** 或 **中文** 切換繁體中文／英文。瀏覽器會記住選擇。這個按鈕只改介面語言，不會改變直播、OBS 或聊天內容。

## 在聊天室傳 GIF

1. 在訊息欄下方按 **GIF · 傳送 GIF**。
2. 從自己的電腦選擇 GIF 圖片。
3. 送出後，貼圖會以一則聊天室訊息出現在所有連線觀眾的聊天室，也會留在最近 100 則聊天歷史內。

限制：只接受 GIF；檔案最多 512 KB、畫布最多 512 × 512 像素；圖片內容會以圖片方式顯示在聊天室，不會疊到 OBS 影片畫面，也不會播放音效。每帳號既有發言間隔、禁言與管理刪除規則同樣適用。請勿上傳私人或未取得使用權的圖片。

## 兩台遠端 OBS 控制測試

### 測試前

- 兩台主播電腦都能打開上方同一個公開 HTTPS 網址，並且各自的 OBS 已完成自己的攝影機、麥克風與串流設定。
- 第一台使用 `live`，第二台使用 `guest`；兩台不能共用串流身分或配對碼。
- OBS WebSocket 只在各自電腦本機使用；不要為測試把 TCP 4455 開到公網。
- 一位第三方觀眾最好用另一台裝置開同一網址，確認畫面和聲音。

### 依序測試

1. 第一位主播在自己的網頁登入並開啟直播間，先開始自己的 OBS。確認第一格為 LIVE。
2. 第二位主播在另一台電腦登入同一個網站，加入第二路直播間，再開始自己的 OBS。確認第二格為 LIVE，兩格都能播放。
3. 兩位各自在自己的網頁打開 **我的 OBS 控制**，分別產生各自的一次性配對碼，並在各自的電腦執行畫面提供的命令。配對碼只能在本人電腦輸入，5 分鐘內使用一次，不要貼到聊天室、eHub、GitHub 或交給另一位主播。
4. 各自按 **讀取 OBS 狀態**。第一台應讀到 `live`，第二台應讀到 `guest`。逐台測試關閉與恢復自己的鏡頭／麥克風，再從網站讀回狀態。
5. 第二位按 **結束我的直播**並確認：第二格變為 OFFLINE，第一格仍為 LIVE。第二位重新開始 OBS 後，第二格應恢復 LIVE。
6. 在聊天室傳一段文字，再傳一張小型 GIF。確認第三方觀眾也看到文字及 GIF；切換中英文後確認介面語言改變，聊天內容本身保持原文。
7. 收播時兩位分別停止自己的 OBS。確認兩格都變為 OFFLINE。

### 通過條件

- 網站兩格分別顯示正確的主播和 LIVE 狀態，影片可播放。
- 網站控制器只影響配對的那台 OBS；停止 guest 不會停止 live。
- 兩台各自的麥克風／鏡頭開關都能讀回正確狀態。
- 文字及 GIF 能到達另一個觀看端；GIF 刪除後不再能從聊天網址讀取。
- 中英文切換立即生效，重新整理後仍保留選擇。

若 OBS 顯示正在串流但網站格子仍 OFFLINE，先停止該台 OBS，請管理者依部署紀錄檢查網站版本、公開 API 和對應 RTMP 路徑；不要改用另一位主播的串流設定。

## 公開網站部署狀態

此功能目前在 GitHub `codex/chat-i18n-gif` 分支。更新公開網站需要管理者將這個版本部署到既有 Azure VM，並確認公開網站的中英按鈕、GIF 聊天 API 及資料保存路徑都正常。公開網站尚未確認部署完成前，不要把舊網站上的測試結果當成這個功能已上線。
