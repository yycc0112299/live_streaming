## 0. 錄影前準備（約 10 分鐘）

### 0-1 告訴我「準備好了」，我會先做這些

- [ ] 確認 Azure VM、網站與串流服務都正常
- [ ] **重置「本場」**：開新的一場，應援榜與本場總點數從 0 開始，畫面才乾淨
- [ ] 清掉聊天室裡舊的不當訊息
- [ ] 第一路（電腦 OBS）開播，確認第二格是空的
- [ ] 錄完通知我，我再關掉 OBS 與 VM（VM 開著會一直計費）

### 0-2 裝置分工

| 代號 | 裝置 | 角色 |
|---|---|---|
| 🖥️ 電腦 | 這台電腦的 Chrome | 觀眾／第二路瀏覽器直播／管理員 |
| 📱 手機 | 你的手機（Chrome 或 Safari） | 觀眾（送禮、聊天、語音留言）／手機直播 |
| 🎥 第一路 | 這台電腦的 OBS（我負責開） | 第一位主播，一直在直播 |

### 0-3 錄影設定

- **電腦錄螢幕**：按 `Win + Alt + R`（Xbox Game Bar）開始／停止，或用 OBS 的「開始錄影」。解析度 1080p，**系統聲音要錄進去**（禮物音效、語音留言、引擎聲都要聽得到）。
- **手機錄螢幕**：
  - iPhone：控制中心 →「螢幕錄製」。
  - Android：快速設定 →「螢幕錄影」→ 選「媒體音訊」。
- 兩台都開「勿擾模式」，避免通知、私人訊息入鏡。
- 瀏覽器縮放 100%，視窗最大化。手機直式。
- **每一幕分開錄一段**，檔名照幕號：`S05_電腦.mp4`、`S05_手機.mp4`。
- **同步記號**：電腦和手機同時錄的幕，開始時先在手機按一下「♡ 喜歡」，兩邊畫面都會冒出愛心，我剪輯時用它對齊。
- 每個動作前後**停 2 秒**，不要太快滑走。
- 點數：手機訪客一開始有 1000 點，整份腳本大約用 300 點，夠用。

## S01 開場：網站總覽（🖥️ 電腦，約 30 秒）

1. 網址列輸入網址後按 Enter。網址開頭是 `https://`，網域是 Azure 的 `cloudapp.azure.com`。
2. 停在首頁 3 秒，慢慢把滑鼠移過這些地方：
   - 左上角 **CLOUD LIVE** 標誌與「● 已連線」綠點
   - 標語「讓每個瞬間，即時相聚。」
   - **雙格播放器**：第一格「● LIVE」正在播 OBS 畫面；第二格顯示「第二台 OBS 尚未推流」
   - 第一格左下角主播名稱「· LIVE」，右下角「🔈 播放聲音」按鈕
   - 播放器下方「N 個連線分頁」「♡ 喜歡」「HLS · 雙 OBS 同台直播」
   - 右側「即時聊天室」
3. 按第一格的 **🔈 播放聲音**，聽到主播聲音後，按鈕會變成「🔊 關閉聲音」。

> 旁白參考：這是我們第九組的雲端直播平台，部署在 Azure 虛擬機上，全程 HTTPS 加密。畫面上有兩個直播格，第一格是電腦 OBS 透過 RTMPS 推上來的直播，觀眾端用低延遲 HLS 播放。兩格可以分別開關聲音。

## S02 分享與 QR Code 加入（🖥️ 電腦 + 📱 手機同時錄，約 30 秒）

1. 🖥️ 按右上角 **↗ 分享直播間**，跳出分享視窗。
2. 🖥️ 按 **複製網址**，畫面出現「觀看連結已複製」。
3. 🖥️ 按 **顯示 QR Code**。
4. 📱 打開手機相機掃 QR Code，點跳出的連結進入網站。
5. 📱 手機自動成為「訪客xxxxxx」，不用註冊。往下滑，送禮區顯示「我的點數 1000」。
6. 🖥️ 關閉分享視窗。播放器下方「連線分頁」數字 +1。

> 旁白參考：觀眾不用安裝任何 App，掃 QR Code 就能進場。系統自動建立訪客身份，並發 1000 點示範點數，點數沒有現金價值。

## S03 聊天室（📱 手機 + 🖥️ 電腦同時錄，約 40 秒）

1. 📱 帳號區「新暱稱」輸入 `小明`，按 **更新暱稱**。
2. 📱 聊天框輸入 `大家好！第一次來看第九組直播`，按 Enter 送出。
3. 🖥️ 電腦聊天室**立刻**出現同一則訊息，暱稱是「小明」。
4. 📱 馬上再送一則 `再一則`，會被擋下並提示發言間隔（每帳號至少隔 5 秒，防洗版）。
5. 📱 按 **GIF · 傳送 GIF**，從相簿選一張 GIF（512 KB 以內），兩邊都顯示動圖。
6. 📱 按 **♡ 喜歡**，🖥️ 電腦畫面飄出愛心，喜歡數 +1（連點太快會提示「請稍候再按讚」）。

> 旁白參考：聊天室用 Socket.IO 走 WebSocket，訊息即時同步給所有人。系統有發言間隔、長度上限與限制詞，也支援 GIF 貼圖。

## S04 3D 禮物動畫＋音效（📱 手機送、🖥️ 電腦看，同時錄，約 60 秒）

**重點：電腦要開聲音，才錄得到禮物音效。**

1. 📱 依序送出六種禮物，**每送一個等動畫播完再送下一個**：
   1. ♥ 小愛心（1 點）：立體愛心旋轉跳動，叮噹聲
   2. 🌹 玫瑰花（5 點）：搖擺的立體玫瑰，琶音
   3. 🚀 小火箭（10 點）：帶尾焰往上飛，呼嘯聲
   4. 🏎️ 小跑車（25 點）：開進來、在中間原地轉一圈、再開走，配 **V8 超跑引擎聲**（怠速 → 拉轉 → 換檔 → 收油回火 → 再加速）
   5. 🎆 星光派對（50 點）：號角加煙火
   6. 🎠 夢幻嘉年華（100 點）：旋轉摩天輪、煙火、鏡頭環繞，音樂盒聲
2. 📱 **連點 3 次小愛心**：電腦端動畫**依序排隊**播放，不會疊在一起。
3. 🖥️ 動畫播到一半時，按送禮區旁邊的 **🔔 禮物音效：開（小聲）**，聲音**立刻停止**，按鈕變成「🔕 禮物音效：關」。再按一次打開。
4. 🖥️ 看「本場應援」總點數即時增加；📱 手機的「我的點數」同步減少。

> 旁白參考：禮物動畫是用 Three.js 即時算出的 3D 模型，有燈光、反光和粒子特效，只在有人送禮時才下載，不拖慢首頁。每種禮物都有獨立音效，音量刻意比人聲小約 14 dB，不會蓋過主播的聲音；觀眾也可以一鍵關閉，正在播的音效會立刻停止。

## S05 本場應援榜與我的名次（📱 手機 + 🖥️ 電腦，約 20 秒）

1. 🖥️ 往下捲到 **🏆 本場應援榜**：手機帳號「小明」排第 1，顯示點數與送禮次數。分數變動的那一列會閃一下。
2. 📱 手機應援榜下方顯示 **「你目前第 1 名 · xxx 點」**。
3. 📱 再送一個小火箭，名次與點數**立刻**更新。
4. 鏡頭帶到應援榜下方的說明文字（依本場累計點數排名，同分時先達到的人排前面）。

> 旁白參考：應援榜依這一場累計送出的點數排名，送禮後立即更新。為了保護隱私，只公開暱稱、點數和次數，不公開帳號；每位觀眾也看得到自己目前的名次。

## S07 點數語音留言＋自選 AI 聲音（📱 手機 + 🖥️ 電腦，約 60 秒）

**重點：電腦要開聲音。**

1. 📱 捲到 **點數語音留言（25 點，最多 120 字）**。
2. 📱 點 **朗讀聲音** 下拉選單，慢慢展開給鏡頭看 9 種聲音：
   1. 曉臻・台灣溫柔
   2. 曉雨・台灣清亮
   3. 曉曉・開心
   4. 曉曉・自然
   5. 曉辰・直播帶貨
   6. 曉曉・興奮（預設）
   7. 曉悠・可愛
   8. 雲哲・台灣男聲
   9. 雲健・熱血解說
3. 📱 選「9 雲健・熱血解說」，按 **▶ 試聽**，手機會唸一段固定的試聽句。
4. 📱 輸入 `主播太強了！這台超跑直接衝啦，大家一起加油！`，按 **花 25 點 送出語音留言**。
5. 🖥️ 電腦畫面上方跳出留言字卡，並用剛才選的聲音唸出來。
6. 📱 **馬上**再送一則：選「2 曉雨・台灣清亮」，輸入 `第九組的期末報告加油！`，送出（已取消語音間隔，不用等）。
7. 🖥️ 電腦用另一種聲音唸出來。

> 旁白參考：語音留言用 Azure AI Speech 的神經網路語音合成。伺服器只合成一次 MP3，所有觀眾聽到的是同一段聲音；送禮的人可以從 9 種聲音中挑選，送出前還能先試聽。一般聊天不會被朗讀，只有花點數的語音留言才會。

## S08 電腦瀏覽器直播：一鍵切換畫面與麥克風（🖥️ 電腦為主，手機一起錄，約 60 秒）

先準備一個要分享的視窗，例如打開我們的簡報 `Group 9.pptx`。

1. 🖥️ 第二格是空的時，按 **直接加入第二路**（說明寫著「加入後 3 分鐘內沒有開始推流，會自動讓出第二路」）。
2. 🖥️ 出現 **手機／瀏覽器直播 · 第二格** 面板。先停 2 秒，給鏡頭看三個按鈕：「📷 只有鏡頭」「🖥️📷 螢幕＋鏡頭」「🖥️ 只有螢幕」，以及「🎤 關閉麥克風」。
3. 🖥️ 選 **📷 只有鏡頭** → 按 **開始瀏覽器直播** → 允許相機與麥克風。
4. 🖥️ 面板狀態變成「LIVE · 已傳送 x MB · xxx kbps」；第二格出現你的鏡頭畫面，名稱旁標示「自己返聽已關閉」（避免回音）。📱 手機上也看得到第二格開播。
5. 🖥️ 按 **🖥️📷 螢幕＋鏡頭** → 選擇簡報視窗分享：第二格變成簡報全畫面，右下角是你的鏡頭子母畫面。**直播不會中斷**。
6. 🖥️ 按 **🖥️ 只有螢幕**：只剩簡報畫面。
7. 🖥️ 按 **📷 只有鏡頭**：螢幕分享自動關閉，回到鏡頭畫面。
8. 🖥️ 按 **🎤 關閉麥克風**：按鈕變紅「🔇 開啟麥克風」，狀態列顯示「🔇 麥克風已關閉」，📱 手機聽不到聲音。再按一次打開。
9. 🖥️ 按 **停止瀏覽器直播**。

> 旁白參考：主播不一定要裝 OBS，用電腦瀏覽器也能直接開播。畫面先在瀏覽器合成成固定 1280×720，再用 WebRTC WHIP 送到伺服器，所以切換「只有鏡頭、螢幕加鏡頭、只有螢幕」時，直播不用重新連線。麥克風也能一鍵開關。

## S09 第二路閒置自動讓位（🖥️ 電腦 + 📱 手機，約 3 分鐘，剪輯時會快轉）

1. 🖥️ 停止直播後，畫面出現 **「⏳ 第二路尚未推流，180 秒後會自動讓出位置給其他人。」**，秒數一直倒數。
2. 兩台都**繼續錄**，等倒數到 0（約 3 分鐘，剪輯時快轉）。
3. 倒數結束後，第二格回到「第二台 OBS 尚未推流」；📱 手機重新出現 **直接加入第二路** 按鈕。

> 旁白參考：如果有人占了第二路卻一直沒開播，3 分鐘後系統會自動讓出位置，讓下一位主播加入。

## S10 手機直播：老師指定的功能（📱 手機為主，🖥️ 電腦一起錄，約 60 秒）

**加分做法：手機關掉 Wi‑Fi，改用 4G／5G 行動網路**，證明不是在同一個區網裡。

1. 📱 按 **直接加入第二路**，出現「手機／瀏覽器直播 · 第二格」面板。
2. 📱「來源」選 **前鏡頭／電腦鏡頭** → 按 **開始手機直播** → 允許相機與麥克風。
3. 🖥️ 電腦第二格出現手機畫面（直式），兩格同時「● LIVE」：電腦 OBS 和手機同台直播。
4. 📱 對著鏡頭揮手、講話；🖥️ 按第二格的 **🔈 播放聲音**，聽得到手機的聲音，延遲約 2 秒。
5. 📱 按 **🎤 關閉麥克風** → 🖥️ 聽不到聲音 → 再按打開。
6. 📱 按 **停止手機直播** → 「來源」改成 **後鏡頭** → 再按 **開始手機直播**，畫面換成後鏡頭拍到的景。
7. 📱 手機自己的第二格標示「自己返聽已關閉」：主播不會聽到自己的回音。
8. 鏡頭停在兩格同時直播的畫面 5 秒，作為這一幕的收尾。

> 旁白參考：這是老師要求的功能：手機直接用瀏覽器加入直播，不用安裝任何 App。手機鏡頭透過 WebRTC 推流，伺服器先驗證登入身份，再由伺服器加上推流金鑰，所以金鑰從來不會出現在手機上。兩個主播的畫面同時在網站上直播。

## S11 管理員功能（🖥️ 電腦用無痕視窗登入管理員 + 📱 手機，約 60 秒）

🖥️ 開一個 **無痕視窗**（`Ctrl + Shift + N`）打開網站，用管理員帳號在「主播／管理員登入」登入。**錄影時不要拍到密碼欄位**，可以先登入好再開始錄。

1. 🖥️ 找到 **聊天室管理**，按 **載入／更新管理面板**。
2. **置頂公告**：輸入 `歡迎來到第九組期末 Demo！`，按 **儲存聊天室規則** → 📱 手機聊天室上方立刻出現 📌 公告。
3. **限制詞**：輸入 `測試禁語`，儲存 → 📱 手機送出含「測試禁語」的訊息 → 被擋下。
4. **檢舉**：📱 在任一則訊息按 **檢舉**，原因填 `示範檢舉` → 🖥️ 管理面板「待處理檢舉」出現這一筆。
5. **禁言**：🖥️ 在檢舉旁按 **禁言 10 分鐘** → 📱 手機送訊息被擋（禁言中）→ 🖥️ 按 **解除禁言** → 📱 又能發言。
6. **刪除訊息**：🖥️ 在聊天室某則訊息按 **刪除** → 兩邊都立刻消失。
7. **管理操作紀錄**：🖥️ 捲到「最近 100 筆管理操作紀錄」，剛剛的操作都記在上面。
8. **抖內控制**：🖥️ 按 **關閉抖內** → 📱 手機禮物按鈕全部變灰 → 🖥️ 按 **重新開啟抖內**。
9. （可選）**帳本管理**：🖥️ 應援帳本裡某筆按 **刪除紀錄** → 點數退回送出者。
10. 錄完把公告清空、限制詞刪掉，按儲存。

> 旁白參考：管理員可以設定置頂公告、發言間隔和限制詞，處理檢舉、禁言、刪除訊息，所有操作都記錄在稽核紀錄裡；也可以隨時開關抖內功能。
