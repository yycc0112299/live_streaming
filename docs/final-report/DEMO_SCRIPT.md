- **電腦錄螢幕**：按 `Win + Alt + R`（Xbox Game Bar）開始／停止，或用 OBS 的「開始錄影」。解析度 1080p，**系統聲音要錄進去**（禮物音效、語音留言、引擎聲都要聽得到）。

  - iPhone：控制中心 →「螢幕錄製」。

- **每一幕分開錄一段**，檔名照幕號：`S05_電腦.mp4`、`S05_手機.mp4`。
- **同步記號**：電腦和手機同時錄的幕，開始時先在手機按一下「♡ 喜歡」，兩邊畫面都會冒出愛心，我剪輯時用它對齊。

## S01 開場：網站總覽（🖥️ 電腦，約 30 秒）

1. 網址列輸入網址後按 Enter。網址開頭是 `https://`，網域是 Azure 的 `cloudapp.azure.com`。
2. 停在首頁 3 秒，慢慢把滑鼠移過這些地方：
   - 左上角 **CLOUD LIVE** 標誌與「● 已連線」綠點
   - 標語「讓每個瞬間，即時相聚。」
   - **雙格播放器**：第一格「● LIVE」正在播 OBS 畫面；第二格顯示「第二台 OBS 尚未推流」
   - 第一格左下角主播名稱「· LIVE」，右下角「🔈 播放聲音」按鈕
   - 播放器下方「N 個連線分頁」「♡ 喜歡」「HLS · 雙 OBS 同台直播」
   - 右側「即時聊天室」
3. 按第一格的 **🔈 播放聲音**，聽到主播聲音後，按鈕會變成「🔊 關閉聲音」。

> 旁白參考：這是我們第九組的雲端直播平台，部署在 Azure 虛擬機上，全程 HTTPS 加密。畫面上有兩個直播格，第一格是電腦 OBS 透過 RTMPS 推上來的直播，觀眾端用低延遲 HLS 播放。兩格可以分別開關聲音。
>
> 畫面註解（只顯示、不念）：Azure VM（Ubuntu 24.04 ARM64，Japan East）· Apache 2.4 + Let's Encrypt HTTPS · OBS → RTMPS（TCP 1936，TLS，/32 IP 白名單）→ MediaMTX 1.21.2 → LL-HLS（1 秒分段、200 ms part）· 端到端延遲約 2 秒 · 兩格分別是 MediaMTX 的 live／guest 路徑

## S03 聊天室（📱 手機 + 🖥️ 電腦同時錄，約 40 秒）

1. 📱 帳號區「新暱稱」輸入 `小明`，按 **更新暱稱**。
2. 📱 聊天框輸入 `大家好！第一次來看第九組直播`，按 Enter 送出。
3. 🖥️ 電腦聊天室**立刻**出現同一則訊息，暱稱是「小明」。

> 畫面註解（只顯示、不念）：Socket.IO over WebSocket（TCP：不遺失、依序到達，W09）· 每帳號發言間隔 ≥ 5 秒 · 單則上限 500 字 · 限制詞過濾 · GIF ≤ 512 KB、≤ 512×512 · React 自動轉義，防 HTML 注入 · 按讚 0.5 秒冷卻

## S04 3D 禮物動畫＋音效（📱 手機送、🖥️ 電腦看，同時錄，約 60 秒）

**重點：電腦要開聲音，才錄得到禮物音效。**

1. 📱 依序送出六種禮物，**每送一個等動畫播完再送下一個**：
   1. ♥ 小愛心（1 點）：立體愛心旋轉跳動，叮噹聲
   2. 🌹 玫瑰花（5 點）：搖擺的立體玫瑰，琶音
   3. 🚀 小火箭（10 點）：帶尾焰往上飛，呼嘯聲
   4. 🏎️ 小跑車（25 點）：開進來、在中間原地轉一圈、再開走，配 **V8 超跑引擎聲**（怠速 → 拉轉 → 換檔 → 收油回火 → 再加速）
   5. 🎆 星光派對（50 點）：號角加煙火
   6. 🎠 夢幻嘉年華（100 點）：旋轉摩天輪、煙火、鏡頭環繞，音樂盒聲
2. 📱 **快速連點 5 次小愛心**：電腦端只播一個動畫，字卡上的 **×2、×3…×5** 一路跳上去（禮物連擊合併，不會排很長的隊）。接著送一個玫瑰再送一個火箭：不同禮物會**依序排隊**播放，大禮物優先。
3. 🖥️ 動畫播到一半時，按送禮區旁邊的 **🔔 禮物音效：開（小聲）**，聲音**立刻停止**，按鈕變成「🔕 禮物音效：關」。再按一次打開。
4. 🖥️ 看「本場應援」總點數即時增加；📱 手機的「我的點數」同步減少。

> 旁白參考：禮物動畫是用 Three.js 即時算出的 3D 模型，有燈光、反光和粒子特效，只在有人送禮時才下載，不拖慢首頁。每種禮物都有獨立音效，音量刻意比人聲小約 14 dB，不會蓋過主播的聲音；觀眾也可以一鍵關閉，正在播的音效會立刻停止。
>
> 畫面註解（只顯示、不念）：Three.js 0.180.0（WebGL）程式建模，無外部素材 · 3D 模組送禮時才延遲載入（gzip 約 134 KB）· 不支援 WebGL 或開啟「減少動態效果」時退回 2D SVG · 每次動畫後釋放 WebGL context · 音效用 Web Audio API 即時合成，RMS −32～−46 dBFS（人聲約 −18 dBFS）· 超跑引擎：V8 點火頻率 = rpm ÷ 15、tanh 失真、隨轉速打開的低通濾波 · 同一人連送同禮物合併為 ×N

1. 📱 捲到 **點數語音留言（25 點，最多 120 字）**。

   2. 曉雨・台灣清亮

   4. 曉曉・自然
   5. 曉辰・直播帶貨

4. 📱 輸入 `主播太強了！這台超跑直接衝啦，大家一起加油！`，按 **花 25 點 送出語音留言**。

>
> 畫面註解（只顯示、不念）：Azure AI Speech 神經語音（F0 免費層，每月 50 萬字）· SSML mstts:express-as 情緒風格（cheerful／excited／livecommercial／sports-commentary-excited）· 伺服器只合成一次 MP3（24 kHz、96 kbps），快取最近 50 則 · 金鑰只存在 VM（root 600），瀏覽器拿不到 · 合成失敗自動退回瀏覽器語音 · 試聽句每種聲音只合成一次

## S08 電腦瀏覽器直播：一鍵切換畫面與麥克風（🖥️ 電腦為主，手機一起錄，約 60 秒）

先準備一個要分享的視窗，例如打開我們的簡報 `Group 9.pptx`。

1. 🖥️ 第二格是空的時，按 **直接加入第二路**（說明寫著「加入後 3 分鐘內沒有開始推流，會自動讓出第二路」）。
2. 🖥️ 出現 **手機／瀏覽器直播 · 第二格** 面板。先停 2 秒，給鏡頭看三個按鈕：「📷 只有鏡頭」「🖥️📷 螢幕＋鏡頭」「🖥️ 只有螢幕」，以及「🎤 關閉麥克風」。
3. 🖥️ 選 **📷 只有鏡頭** → 按 **開始瀏覽器直播** → 允許相機與麥克風。
4. 🖥️ 面板狀態變成「LIVE · 已傳送 x MB · xxx kbps」；第二格出現你的鏡頭畫面，名稱旁標示「自己返聽已關閉」（避免回音）。📱 手機上也看得到第二格開播。
5. 🖥️ 按 **🖥️📷 螢幕＋鏡頭** → 選擇簡報視窗分享：第二格變成簡報全畫面，右下角是你的鏡頭子母畫面。**直播不會中斷**。
6. 🖥️ 按 **🖥️ 只有螢幕**：只剩簡報畫面。
7. 🖥️ 按 **📷 只有鏡頭**：螢幕分享自動關閉，回到鏡頭畫面。
8. 🖥️ 按 **🎤 關閉麥克風**：按鈕變紅「🔇 開啟麥克風」，狀態列顯示「🔇 麥克風已關閉」，📱 手機聽不到聲音。再按一次打開。
9. 🖥️ **即時字幕**：在「📝 即時字幕」面板，辨識語言選「中文（台灣）」→ 按 **▶ 開始字幕** → 允許麥克風 → 對著電腦說 `大家好，這是第九組的即時字幕功能`。📱 手機上第二格畫面下方即時出現字幕；面板也顯示「辨識中：…」。
10. 📱 手機按播放器下方的 **CC 字幕：開**，變成「字幕：關」，字幕消失；再按打開。
11. 🖥️ 按 **⏹ 停止字幕**，再按 **停止瀏覽器直播**。

> 旁白參考：主播不一定要裝 OBS，用電腦瀏覽器也能直接開播。畫面先在瀏覽器合成成固定 1280×720，再用 WebRTC WHIP 送到伺服器，所以切換「只有鏡頭、螢幕加鏡頭、只有螢幕」時，直播不用重新連線。麥克風也能一鍵開關。主播還可以開啟即時字幕，說的話會即時變成文字顯示給所有觀眾，觀眾也能自己開關字幕。
>
> 畫面註解（只顯示、不念）：canvas 合成 1280×720 @ 30 fps，切換版面不重新連線、不改解析度 · Web Worker 驅動重繪，切到其他視窗也不凍結 · WebRTC WHIP（H.264 優先、Opus 音訊），媒體走 UDP 8189（TCP 備援）· 伺服器驗證登入身分後代加推流密碼 · 即時字幕：Web Speech API → Socket.IO → 所有觀眾，限制詞遮成＊

## S09 讓出第二路：主動離開＋閒置自動讓位（🖥️ 電腦 + 📱 手機，約 20 秒；自動讓位部分可選）

1. 🖥️ 停止直播後，畫面出現 **「⏳ 第二路尚未推流，180 秒後會自動讓出位置給其他人。」**，秒數一直倒數。停 5 秒讓鏡頭拍到倒數。
2. 🖥️ 按 **🚪 離開第二路** → 確認：第二格立刻空出來；📱 手機重新出現 **直接加入第二路** 按鈕。
3. （可選）如果想拍「自動讓位」：步驟 2 先不要按，兩台繼續錄到倒數 0（約 3 分鐘，剪輯時快轉），第二格會自動空出來。

> 旁白參考：主播可以一鍵離開第二路；如果有人占了位置卻一直沒開播，3 分鐘後系統也會自動讓位，讓下一位主播加入。
>
> 畫面註解（只顯示、不念）：伺服器每 2 秒輪詢 MediaMTX API · 占用第二路但 180 秒沒有推流就自動釋放 · 推流中會重置計時 · MediaMTX 暫時連不上時不踢人

## S10 手機直播：老師指定的功能（📱 手機為主，🖥️ 電腦一起錄，約 60 秒）

**加分做法：手機關掉 Wi‑Fi，改用 4G／5G 行動網路**，證明不是在同一個區網裡。

1. 📱 按 **直接加入第二路**，出現「手機／瀏覽器直播 · 第二格」面板。
2. 📱「來源」選 **前鏡頭／電腦鏡頭** → 按 **開始手機直播** → 允許相機與麥克風。
3. 🖥️ 電腦第二格出現手機畫面（直式），兩格同時「● LIVE」：電腦 OBS 和手機同台直播。
4. 📱 對著鏡頭揮手、講話；🖥️ 按第二格的 **🔈 播放聲音**，聽得到手機的聲音，延遲約 2 秒。
5. 📱 按 **🎤 關閉麥克風** → 🖥️ 聽不到聲音 → 再按打開。
6. 📱 按 **停止手機直播** → 「來源」改成 **後鏡頭** → 再按 **開始手機直播**，畫面換成後鏡頭拍到的景。
7. 📱 手機自己的第二格標示「自己返聽已關閉」：主播不會聽到自己的回音。
8. **斷線自動重連**：📱 直播中把手機的 Wi‑Fi 關掉（或開飛航模式 3 秒再關掉）→ 手機面板顯示「網路中斷，自動重新連線中（1/12）」→ 網路回來後自動回到 **LIVE**，不用重按開始。🖥️ 電腦第二格短暫停頓後恢復。
9. **停止朗讀**：🖥️ 電腦（觀眾）送一則長一點的語音留言 → 📱 手機（現在是主播）在留言字卡上按 **⏹ 停止朗讀** → 兩邊的朗讀同時停止、字卡消失。
10. 鏡頭停在兩格同時直播的畫面 5 秒，作為這一幕的收尾。

> 旁白參考：這是老師要求的功能：手機直接用瀏覽器加入直播，不用安裝任何 App。手機鏡頭透過 WebRTC 推流，伺服器先驗證登入身份，再由伺服器加上推流金鑰，所以金鑰從來不會出現在手機上。兩個主播的畫面同時在網站上直播。手機在 Wi‑Fi 和行動網路之間切換、短暫斷線時，會自動重新連線；主播也可以一鍵停止正在朗讀的語音留言。
>
> 畫面註解（只顯示、不念）：手機只需瀏覽器（HTTPS 才能使用相機）· getUserMedia → WebRTC WHIP · 經 4G／5G 行動網路推流 · 斷線重連間隔 1、2、4、8、15 秒，最多 12 次；網路恢復（online 事件）立即重試 · 自己的那一格自動靜音，避免回音 · overridePublisher: false，同一格同時只允許一個來源

## S11 管理員功能（🖥️ 電腦用無痕視窗登入管理員 + 📱 手機，約 60 秒）

🖥️ 開一個 **無痕視窗**（`Ctrl + Shift + N`）打開網站，用管理員帳號在「主播／管理員登入」登入。**錄影時不要拍到密碼欄位**，可以先登入好再開始錄。

1. 🖥️ 找到 **聊天室管理**，按 **載入／更新管理面板**。
2. **置頂公告**：輸入 `歡迎來到第九組期末 Demo！`，按 **儲存聊天室規則** → 📱 手機聊天室上方立刻出現 📌 公告。
3. **限制詞**：輸入 `測試禁語`，儲存 → 📱 手機送出含「測試禁語」的訊息 → 被擋下。
4. **檢舉**：📱 在任一則訊息按 **檢舉**，原因填 `示範檢舉` → 🖥️ 管理面板「待處理檢舉」出現這一筆。
5. **禁言**：🖥️ 在檢舉旁按 **禁言 10 分鐘** → 📱 手機送訊息被擋（禁言中）→ 🖥️ 按 **解除禁言** → 📱 又能發言。
6. **刪除訊息**：🖥️ 在聊天室某則訊息按 **刪除** → 兩邊都立刻消失。
7. **管理操作紀錄**：🖥️ 捲到「最近 100 筆管理操作紀錄」，剛剛的操作都記在上面。
8. **抖內控制**：🖥️ 按 **關閉抖內** → 📱 手機禮物按鈕全部變灰 → 🖥️ 按 **重新開啟抖內**。
9. （可選）**帳本管理**：🖥️ 應援帳本裡某筆按 **刪除紀錄** → 點數退回送出者。
10. **🩺 直播健康面板**：🖥️ 按 **打開即時監控（每 3 秒更新）**：兩格各顯示來源（OBS／瀏覽器或手機）、上傳碼率、已接收量、影音軌、連續直播時間，正常時顯示「✅ 狀態正常」；下方是 VM 的記憶體與 CPU 負載。停 5 秒讓數字跳動。
11. **📊 本場統計**：🖥️ 顯示直播時長、最高同時連線、按讚、聊天訊息、送禮次數、總應援點數、送禮人數、語音留言數與第一名支持者。按 **更新統計**。
12. 錄完把公告清空、限制詞刪掉，按儲存。
13. **最後**（S13 收尾拍完之後再做）：🖥️ 按 **結束本場並開新一場** → 確認 → 應援榜、按讚、本場點數歸零，下方出現「上一場統計」。這一場的統計可以截圖放進簡報的 Results 頁。

> 旁白參考：管理員可以設定置頂公告、發言間隔和限制詞，處理檢舉、禁言、刪除訊息，所有操作都記錄在稽核紀錄裡；也可以隨時開關抖內功能。直播健康面板即時顯示每一路的碼率和狀態，出問題會直接提示；本場統計記錄這一場的觀看、互動和應援數字，主播可以一鍵結束這一場並開新的一場。
>
> 畫面註解（只顯示、不念）：所有管理操作寫入 audit 稽核表 · 禁言以帳號計時 · 健康面板每 3 秒更新，碼率由 MediaMTX bytesReceived 的差值計算 · 本場統計由 SQLite 即時彙總 · VM 每天 03:00（台北時間）自動關機＋每月預算警示，控制學生額度
