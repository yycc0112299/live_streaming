## 聲音與文字規則

- **原音優先**：有禮物音效、語音朗讀、直播聲音的時段，不加旁白、不加音樂。
- 旁白只放在安靜的空檔；放不下的句子只顯示字幕。
- 每段有標題字卡；技術資訊用畫面註解（只顯示、不念），內容照 `DEMO_SCRIPT.md` 各幕的「畫面註解」。
- 不加背景音樂。
