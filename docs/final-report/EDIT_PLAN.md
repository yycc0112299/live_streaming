## 製作方式

1. 用 ffmpeg 依檔名時間對齊電腦與手機影片（0～3 秒差），左右合成。
2. 每段計算原音音量（每 0.1 秒），找出有聲音的時段。
3. 英文旁白用 Azure AI Speech（`en-US-AndrewMultilingualNeural`）逐句合成，只放進安靜空檔；放不下時最多停留最後一格 4～7 秒；仍放不下就只顯示字幕。
4. 標題、技術註解、中英字幕用 ASS 燒進畫面（微軟正黑體＋Segoe UI）。
5. 各段用 concat 濾鏡重新編碼合併（直接複製串流會讓時間戳錯亂）。
## 聲音與文字規則

- **原音優先**：有禮物音效、語音朗讀、直播聲音的時段，不加旁白、不加音樂。
- 旁白只放在安靜的空檔；放不下的句子只顯示字幕。
- 每段有標題字卡；技術資訊用畫面註解（只顯示、不念），內容照 `DEMO_SCRIPT.md` 各幕的「畫面註解」。
- 不加背景音樂。
