# Demo 影片：你的完整步驟（錄影 → 交檔 → 剪輯 → 放進簡報）

這份是給你照著做的**操作清單**：每一步做什麼、怎麼錄、要講什麼。
每一幕更細的畫面說明與技術註解在 [`DEMO_SCRIPT.md`](DEMO_SCRIPT.md)，剪輯時我會用到；你錄影時看這份就夠了。

**時程建議**：簡報要在 **11/29（日）23:59 前**上傳 Moodle。最晚 **11/28 晚上**錄完交給我，我才有時間剪輯並讓你確認。

## 第 1 步：錄影前一天或錄影前 30 分鐘的準備

### 1-1 準備好這些東西

- [ ] **電腦**：這台電腦，用 Chrome 開網站。
- [ ] **手機**：充飽電，用 Chrome（Android）或 Safari（iPhone）。
- [ ] **耳機**：電腦用的有線或藍牙耳機（第 10 幕防回音用）。
- [ ] **管理員帳號密碼**：第 11 幕要登入。密碼自己記好，**不要給我、也不要拍進影片**。
- [ ] **一個要分享的視窗**：例如打開 `Group 9.pptx`（第 8 幕「螢幕＋鏡頭」用）。
- [ ] **一張小 GIF**（512 KB 以內）先存進手機相簿（第 3 幕用）。
- [ ] **看台詞的地方**：把這份指南印出來，或用第三台裝置（平板、另一支手機）打開，錄影時方便看台詞。

### 1-2 設定電腦錄影（Xbox Game Bar）

1. 開 Windows **設定 → 遊戲 → 擷取**：
   - **錄製遊戲時錄製音訊**：開啟。
   - **影片畫面播放速率**：30 fps。
   - **影片品質**：標準（檔案比較小，傳檔比較快）。
2. 打開 Chrome 網站後按 `Win + G` 叫出 Game Bar →「擷取」小工具裡的 **🎤 麥克風圖示**按成開啟（錄影時會收你的聲音）。
3. 測試：按 `Win + Alt + R` 開始，講一句話、在網頁播一段聲音，再按 `Win + Alt + R` 停止 → 到 `C:\Users\USER\Videos\Captures` 播放，確認**有畫面、有網頁聲音、有你的聲音**。

> Game Bar 只錄「目前這個視窗」。錄影時 Chrome 要在最前面並最大化；第 8 幕分享簡報時，畫面上看到的仍然是 Chrome 裡的直播畫面，這樣就對了。

### 1-3 設定手機錄影

- **iPhone**：設定 → 控制中心 → 加入「螢幕錄製」。錄影時**長按**螢幕錄製按鈕，把「麥克風」**關掉**（你的聲音由電腦收音，避免兩邊重複）。
- **Android**：下拉快速設定 →「螢幕錄影」→ 音訊選 **媒體音訊**（不要選麥克風）。

### 1-4 兩台裝置都要

- [ ] 開 **勿擾模式**（避免通知或私人訊息入鏡）。
- [ ] 螢幕亮度調高、自動鎖定改成「永不」或 5 分鐘以上。
- [ ] 電腦 Chrome 縮放 100%、視窗最大化；手機直式。
- [ ] 錄影環境安靜（**原音會完整保留在影片裡**），關掉風扇和電視，請旁邊的人不要講話。

## 第 3 步：照順序錄 13 幕

### 每一幕都這樣做

1. 先把畫面停在這一幕的起點。
2. **開始錄影**（需要哪台就錄哪台；兩台都要錄的，先按電腦、再按手機）。
3. **兩台都錄的幕**：開始後先在手機按一下 **♡ 喜歡**（兩邊畫面同時冒出愛心，我用它對齊兩支影片）。
4. 照下面的「動作」做，在「🎤 你說」的地方講台詞。**每個動作前後停 2 秒**。
5. **停止錄影**。
6. 檔名照幕號改（可以錄完全部再一起改）：`S01_電腦.mp4`、`S02_手機.mp4`……

### 講話的原則

- 台詞**不用背、不用一字不差**，用自己的話講出意思就好；講錯了停 2 秒重講那一句，我會剪掉。
- **有聲音在播的時候不要講話**（禮物音效、引擎聲、語音留言朗讀、直播的聲音），等它播完再講。這段原音會完整保留，旁白也不會蓋上去。
- 想講英文也可以：下面每句都附英文版。只要選定一種語言，**整支影片都用同一種**。
- 不想講話也可以：整支都不講，我用 AI 旁白配在安靜的空檔。
